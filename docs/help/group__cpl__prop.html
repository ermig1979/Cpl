Definition: Prop.h:46

Declares a named property field with a default value and a description.

Parameters
type- Stored value type. Must support Cpl::ToStr, Cpl::ToVal and operator==.
name- Field name. Used as the member identifier and as the second half of the dotted map key.
value- Default value. Changed() is true when the stored value differs from this default.
descr- Description string returned by Description().
Note
Limited() stays false, so XML "value_min" and "value_max" are a single space. Assignment through operator() still uses ParamLimited range checks against std::numeric_limits<type>::min() and max().

Declares a named property field with a default, an inclusive [min, max] range and a description.

Parameters
type- Stored value type. Must be comparable with operator<=.
name- Field name. Used as the member identifier and as the second half of the dotted map key.
value- Default value. Must satisfy min <= value <= max (asserted in the constructor).
min- Inclusive lower bound written to XML "value_min".
max- Inclusive upper bound written to XML "value_max".
descr- Description string returned by Description().
Note
Limited() is true. operator() rejects assignments outside [min, max] and restores value. ToVal and XML load still write the parsed value without that check.
