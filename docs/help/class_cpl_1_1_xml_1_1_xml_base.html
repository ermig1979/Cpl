Detailed Description

template<class Ch = char>
class Cpl::Xml::XmlBase< Ch >

Shared name, value and parent pointer of XmlNode and XmlAttribute.

Template Parameters
Ch- Character type of the name and value. Default is char.
Note
Name() and Value() store pointers; they do not copy characters. The pointed-to data must outlive this object. When no name or value is set, Name() and Value() return a static empty string and the size accessors return 0.
