Detailed Description

template<class Ch = char>
class Cpl::Xml::File< Ch >

Loads a zero-terminated XML source buffer from a file, memory or input stream.

Template Parameters
Ch- Character type of the buffer. Default is char.
Note
Data() is suitable as the text argument of XmlDocument::Parse. Size() includes the terminating zero, so the character count passed to Parse() is Size() - 1 when the buffer is non-empty.
