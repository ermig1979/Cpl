Detailed Description

In-place XML DOM parser, printer and file loader.

Note
Parse() writes into the source buffer unless non-destructive flags are set. Nodes, attributes and strings are allocated from MemoryPool and are freed only when the pool (or XmlDocument) is cleared or destroyed.
