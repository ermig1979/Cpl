Detailed Description

Rectangular table with column headers, cell values, alignment and optional HTML/text export.

Note
The table size is fixed at construction. Headers, row properties and cells are then filled with SetHeader, SetRowProp and SetCell. GenerateText writes an ASCII table; GenerateHtml writes an HTML table, optionally with CSS, JavaScript and click-to-sort headers.

Builds an HTML representation of the table.

Parameters
[in]indent- Initial indent level of the Html writer. Each level is two spaces.
[in]firstTime- If true, emit the CSS style block (and the sort script when sortable is true). Set false when the page already contains those assets from an earlier table.
[in]sortable- If true, add clickable column headers and JavaScript that sorts rows.
[in]ignoreAlignment- If true, all columns are centered.
Returns
HTML markup of the table, including optional style and script blocks.
Note
When sortable is true, right-aligned columns are rendered as centered, and a column whose cells are all numeric is sorted as numbers. Cell links become href anchors. Bold rows use a gray background.
