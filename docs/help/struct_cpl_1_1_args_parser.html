Detailed Description

Command-line argument parser intended to be used as a base class.

Note
Inherit ArgsParser and call GetArg, GetArg2, GetArgs or HasArg from the derived class. An argument name is matched as a prefix of an argv token starting from index 1. In the default mode the value is the next argv token (-name value). In the alternative mode the value follows '=' in the same token (-name=value).

Stores the argument list and the value syntax mode.

Parameters
[in]argc- Number of arguments, typically the argc parameter of main.
[in]argv- Argument vector, typically the argv parameter of main. argv[0] is the application path.
[in]alt- Value syntax. If false, the value is the next argv token (-name value). If true, the value follows '=' in the same token (-name=value).
