Parameters

Specializes Cpl::ToStr and Cpl::ToVal for an enum declared by CPL_PARAM_ENUM_DECL.

Parameters
ns- Enclosing namespace of the enum, or CPL_NOARG for the global namespace.
type- Enumeration type name.
unknown- Suffix of the unknown sentinel, typically Unknown.
size- Suffix of the count sentinel, typically Size.
...- Comma-separated enumerator identifiers. ToStr strips the type name prefix from each name.
Note
ToVal matches names case-insensitively through Cpl::ToEnum. Used by CPL_PARAM_ENUM0 through CPL_PARAM_ENUM3.
