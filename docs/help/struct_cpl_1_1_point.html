Detailed Description

template<typename T>
struct Cpl::Point< T >

Two-dimensional point with coordinates of type T.

Template Parameters
T- Coordinate type.
Note
Coordinates can be converted from other types with Convert. Arithmetic operators act component-wise. Comparison requires both coordinates to match.
