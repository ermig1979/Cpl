◆ TimeCounter()

int64_t TimeCounter ( )

Returns the current value of the high-resolution time counter.

Returns
Counter ticks. On Windows this is QueryPerformanceCounter. On GCC this is CLOCK_REALTIME expressed in nanoseconds.
Note
Convert a difference of two TimeCounter values to seconds or milliseconds with Seconds() or Miliseconds(). The tick rate is given by TimeFrequency().

◆ TimeFrequency()

int64_t TimeFrequency ( )

Returns the number of TimeCounter ticks in one second.

Returns
Ticks per second. On Windows this is QueryPerformanceFrequency. On GCC this is 10^9.

◆ Time()

double Time ( )

Returns the current time in seconds.

Returns
TimeCounter() divided by TimeFrequency().
Note
On Windows the origin is the QueryPerformanceCounter epoch. On GCC the origin is the Unix epoch (CLOCK_REALTIME).
