Detailed Description

template<typename T>
struct Cpl::Rectangle< T >

Axis-aligned rectangle with origin (x, y) and size (w, h) of type T.

Template Parameters
T- Coordinate and size type.
Note
The origin is the top-left corner when y increases downward. Right() is x + w and Bottom() is y + h. Point containment is half-open: [x, x + w) x [y, y + h).
