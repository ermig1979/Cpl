Detailed Description

template<class T>
struct Cpl::Param< T >

Named parameter node that stores a value of type T and can be saved or loaded as XML or YAML.

Template Parameters
T- Stored value type. A scalar, a user struct of Param fields, std::vector or std::map depending on the derived class.
Note
Declare fields with CPL_PARAM_VALUE, CPL_PARAM_LIMITED, CPL_PARAM_STRUCT, CPL_PARAM_VECTOR or CPL_PARAM_MAP and a CPL_PARAM_HOLDER root. operator() returns the stored value. Save and Load write or read a tree whose node names are the field names.
