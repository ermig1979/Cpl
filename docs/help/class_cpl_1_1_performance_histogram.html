Detailed Description

Adaptive histogram of measured time samples used to estimate quantiles.

Note
Samples are TimeCounter ticks. Quantile() converts the estimated tick value to milliseconds. A histogram with size 0 is disabled and stores no samples. The class is compiled only when CPL_PERF_ENABLE is defined.
