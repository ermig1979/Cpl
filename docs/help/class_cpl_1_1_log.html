Detailed Description

Thread-safe logger with multiple writers, severity levels and configurable message formatting.

Note
The Log class is compiled only when CPL_LOG_ENABLE is defined. Otherwise the logging macros are empty.

◆ Level

enum Level

Severity of a log message. A greater value means a more verbose message. A writer with a given level receives messages whose level is less or equal to that value.

Enumerator
None 

Logging disabled. Messages with this level are never written.

Error 

Error messages.

Warning 

Warning messages.

Info 

Informational messages.

Verbose 

Verbose diagnostic messages.

Debug 

Debug messages (most detailed).

◆ Flags

enum Flags

Bit flags that control the prefix written in front of a formatted log message. Flags can be combined with bitwise OR.

Enumerator
WriteThreadId 

Write the current thread identifier.

WritePrefix 

Write the severity name (Error, Warning, Info, Verbose, Debug).

PrettyThreadId 

Replace the native thread id with a sequential 3-digit name.

ColorezedPrefix 

Colorize the severity name for terminal output.

WriteDate 

Write the current date.

WriteTime 

Write the current time.

DefaultFlags 

Default formatting: thread id, pretty thread name and severity prefix.

BashFlags 

Default formatting plus a colorized severity prefix.
