◆ Random()

double Random ( double  min,
double  max 
)

Returns a pseudo-random floating-point value in the closed range [min, max].

Parameters
[in]min- Lower bound of the range.
[in]max- Upper bound of the range.
Returns
A value in [min, max] computed as min + rand() / RAND_MAX * (max - min).
Note
Uses the C library rand() generator. Call srand() to seed it. Not suitable for cryptographic use.

Busy-waits for approximately the given duration.

Parameters
[in]seconds- Duration to wait.
Note
Occupies the calling thread by spinning until TimeCounter() advances by seconds * TimeFrequency() ticks. Intended for tests and dummy load, not for precise timing or yielding the CPU.
