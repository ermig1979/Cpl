◆ CurrentDateTimeString()

String CurrentDateTimeString ( bool  date = true,
bool  time = true,
int  msDigits = CPL_CURRENT_DATE_TIME_PRECISION 
)

Returns the current local date and/or time as a string.

Parameters
[in]date- If true, include the date as YYYY.MM.DD. True by default.
[in]time- If true, include the time as HH:MM:SS[.fraction]. True by default.
[in]msDigits- Number of fractional-second digits after the time. Values greater than CPL_CURRENT_DATE_TIME_PRECISION are clamped. 0 omits the fraction.
Returns
Concatenation of the requested parts, separated by a space when both date and time are included.
Note
The default of msDigits is CPL_CURRENT_DATE_TIME_PRECISION (3 on Windows, 6 on Linux).
