Detailed Description

Formatting options for Serialize().

Note
SpaceIndentation must be at least 2 or Serialize() throws OperationException.

Sets the four formatting fields.

Parameters
[in]spaceIndentation- Spaces added per nesting level. Must be at least 2 when serializing.
[in]scalarMaxLength- Maximum plain-scalar length before folded style is used. 0 disables that limit.
[in]sequenceMapNewline- If true, a map that is a sequence item starts on a new line.
[in]mapScalarNewline- If true, a scalar that is a map value starts on a new line.
