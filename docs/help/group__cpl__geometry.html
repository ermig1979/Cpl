◆ CrossScore()

int CrossScore ( const TPoint< T > &  a1,
const TPoint< T > &  a2,
const TPoint< T > &  b1,
const TPoint< T > &  b2 
)

Classifies the intersection of segments a1-a2 and b1-b2.

Template Parameters
T- Coordinate type.
TPoint- Point template. Must provide x and y.
Parameters
[in]a1- Start of the first segment.
[in]a2- End of the first segment.
[in]b1- Start of the second segment.
[in]b2- End of the second segment.
Returns
0 if the segments are parallel or do not intersect. Otherwise the magnitude is 1 if they meet at an endpoint and 2 if they cross in the interior. The sign is positive when the direction from a1-a2 to b1-b2 is a left turn (positive 2D cross product), negative otherwise.

Tests whether a point lies inside a polygon or on its boundary.

Parameters
