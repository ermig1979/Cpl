Detailed Description

template<class Ch = char>
class Cpl::Xml::XmlDocument< Ch >

XML document: a NodeDocument root plus the MemoryPool that owns the tree.

Template Parameters
Ch- Character type of the parsed text. Default is char.
Note
Parse() writes into the source buffer unless non-destructive flags are set. The source buffer must remain valid for the lifetime of the document.

Member Function Documentation

◆ Parse()

void Parse ( Ch *  text,
size_t  length 
)

Parses zero or more root-level nodes from text and appends them to this document.

Template Parameters
Flags- Combination of Parse* flag constants. Use ParseDefault for the default behaviour.
Parameters
[in,out]text- Source XML. Not copied. May be overwritten unless Flags includes ParseNonDestructive (and does not include whitespace-normalizing flags). Must be readable for length characters and should be zero-terminated.
[in]length- Number of characters in text, not counting a required terminator.
Note
Existing children and attributes are removed first. Throws ParseError when the text is not well-formed XML or when a required '<' is missing.
