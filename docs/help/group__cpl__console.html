◆ Stylized()

String Stylized ( const String &  text,
Format  format = FormatDefault,
Foreground  foreground = ForegroundDefault,
Background  background = BackgroundDefault,
Reset  reset = ResetAll 
)

Wraps text in ANSI/VT100 SGR escape sequences on Linux; returns the original text on other platforms.

Parameters
[in]text- Text to style.
[in]format- Text attributes such as bold or underline.
[in]foreground- Foreground (text) color.
[in]background- Background color.
[in]reset- Reset sequence appended after the text.
Returns
Styled string on Linux, unmodified text otherwise.
Note
Escape sequences are emitted only when compiled for Linux.
